# 🛡️ Remnawave Auto Installer
<sub>Автоматический установщик Remnawave Panel + Node с NGINX, SSL и cookie-защитой</sub>
___

## 🚀 Быстрый старт

```bash
bash <(curl -Ls https://raw.githubusercontent.com/DanteFuaran/dfc-remna-install/refs/heads/main/install-wrapper.sh)
```

<sub>После установки управление доступно через команду **`dfc-remna-install`** или **`dfc-ri`**</sub>

___

<h2> $${\color{blue}✨ Ключевые\ возможности}$$ </h2>

<details>

<summary>$${\color{gray}Показать\ подробности:}$$<br></summary>

### 🔐 Безопасность
> **Cookie-защита доступа** - дополнительный слой защиты панели через уникальные cookie-ссылки<br>
> **Автоматические SSL-сертификаты** - Let's Encrypt через Cloudflare DNS-01 или ACME HTTP-01<br>
> **Смена cookie в один клик** - мгновенная инвалидация старых ссылок доступа

### 🌐 Управление доменами
> **Смена домена в любое время** - изменение доменов панели и подписки без переустановки<br>
> **Автоматическое обновление SSL** - новые сертификаты получаются автоматически при смене домена<br>
> **Поддержка нескольких нод** - гибкая настройка доменов для selfsteal/нод

### 💾 Резервное копирование
> **Автоматические бэкапы** - сохранение базы данных PostgreSQL в архив с датой/временем<br>
> **Быстрое восстановление** - загрузка БД из любого .sql.gz архива в папке `/opt/remnawave/backups/`<br>
> **Миграция между серверами** - перенос данных через бэкапы

### ⚙️ Управление
> **Интерактивное меню** - простое управление всеми компонентами системы<br>
> **Обновления в один клик** - автоматическое обновление панели, ноды и скрипта управления<br>
> **Гибкая установка** - выбор: полная установка, только панель или только нода<br>
> **Мониторинг логов** - просмотр логов панели, ноды, nginx и PostgreSQL в реальном времени

</details>

<h2> $${\color{blue}📋 Требования}$$ </h2>

<details>
  
<summary>$${\color{gray}Показать\ подробности:}$$<br></summary>

### 🖥️ Система
> **Ubuntu** 22.04 / 24.04  
> **Debian** 11 / 12  
> Доступ **root** или возможность использовать `sudo`

<br>

### 🌐 Домены и DNS
> 3 домена/поддомена с **A-записями** на IP сервера<br>
> Для полной установки: домены для панели, подписки и selfsteal/ноды

<br>

### 🔐 SSL-сертификаты
> Email для **Let's Encrypt**<br>
> API Token для **Cloudflare DNS-01** (опционально, для автоматического получения сертификатов)

<br>

### 📦 Версия Remnawave
> **2.5.24** или выше

<sub>⚠️ $${\color{orange}Все\ зависимости\ (Docker,\ Docker\ Compose,\ Certbot)\ устанавливаются\ автоматически.}$$</sub>

</details>

### 📦 Что сделает скрипт
> ✅ Проверит систему и совместимость<br>
> ✅ Установит Docker и Docker Compose<br>

> ✅ Развернет PostgreSQL, Remnawave Panel и Node<br>
> ✅ Настроит NGINX с cookie-защитой<br>
> ✅ Создаст учетные данные суперадмина<br>
> ✅ Установит панель управления `dfc-remna-install` / `dfc-ri`

</details>

<h2> $${\color{red}🔧 Частые\ ошибки}$$ </h2>

<details>

<summary>$${\color{gray}Показать\ подробности:}$$<br></summary>

### Убедитесь что:
> ✅ Все домены корректно указывают на IP сервера через **A-записи** в DNS<br>
> ✅ Порты **80**, **443** и **8080** свободны и не заняты другими службами<br>
> ✅ Firewall разрешает входящие подключения на портах **80**, **443**, **8080**<br>
> ✅ Email для Let's Encrypt указан правильно<br>
> ✅ При использовании Cloudflare DNS-01 указан корректный **API Token**<br>
> ✅ Версия Docker и Docker Compose актуальна (скрипт обновит автоматически)

### Решение проблем:
> 📋 Используйте **диагностику системы** в панели управления `dfc-ri`<br>
> 📜 Проверьте логи компонентов через панель управления<br>
> 🔄 Попробуйте перезапустить сервисы через `dfc-ri`<br>
> 🆘 Если проблема не решается - откройте **Issue** на GitHub с логами

</details>

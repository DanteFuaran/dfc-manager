## 🚀 Установка
 
```bash
cd /opt && bash <(curl -s https://raw.githubusercontent.com/DanteFuaran/dfc-manager/main/dfc-manager.sh)
```
 
Скрипт самостоятельно:
 
- Установит `git`, если он отсутствует.
- Скачает репозиторий в `/usr/local/dfc-manager`.
- Создаст глобальные команды `dfc-manager` и короткий алиас `dfc` в `/usr/local/bin`.
- Запустит интерактивное меню.
 
---
 
## ⚙️ Запуск и обновление
 
| Команда | Действие |
|---|---|
| `dfc` | Запуск меню (короткий алиас) |
| `dfc-manager` | Запуск меню (полное имя) |
 
При каждом запуске скрипт сравнивает локальный коммит с `main` через GitHub API и автоматически подтягивает обновления (`git fetch` + `reset --hard`). Перезапуск с обновлённым кодом происходит без участия пользователя.

## 📦 Remnawave — панель VPN
 
### Установка компонентов
 
Мастер задаёт два вопроса (страница подписки и нода — на этом VPS или на отдельном сервере) и собирает одну из конфигураций:
 
| Конфигурация | Состав |
|---|---|
| Полная | Панель + Нода + Страница подписки |
| Панель + Подписка | Нода — на отдельном сервере |
| Панель + Нода | Подписка — на отдельном сервере |
| Только панель | Минимальная установка |
| Подключить ноду | Добавляет ноду к уже работающей панели |
| Только страница подписки | Сервис `subscribe-page` для существующей панели |
| Только нода | Нода для подключения к удалённой панели |
 
### Управление сервисами
 
| Пункт | Действие |
|---|---|
| ▶ Запустить сервисы | `docker compose up -d` для всех контейнеров |
| ⏹ Остановить сервисы | `docker compose down` |
| 📋 Просмотр логов | Живой поток (`docker compose logs -f`), выход — `Ctrl+C` |
| 🔄 Обновить панель/ноду | Pull свежих образов и перезапуск без потери данных |
 
### Настройки доступа
 
| Пункт | Действие |
|---|---|
| 🔐 Сбросить суперадмина | Новый логин и пароль без переустановки |
| 🍪 Сменить cookie | Все старые ссылки немедленно инвалидируются |
| 🔗 Показать ссылку входа | Текущая cookie-ссылка для входа |
| 🔒 443 ↔ 8443 | Переключение порта прямого доступа |
| 🌐 Сменить домены | Подменю: панель / страница подписки / нода (с автоматическим перевыпуском SSL) |
| 🎨 Сменить сайт-заглушку | Замена HTML-шаблона маскировки на корневом домене ноды |

## 🗑 Удаление компонентов
 
Меню показывает только то, что фактически установлено:
 
```
🖥  Remnawave (панель)
🌐  Remnawave (нода)
📄  Remnawave (страница подписки)
📊  Beszel (мониторинг)
📊  Beszel (агент)
📡  MTProto (прокси)
──────────────────────────────────────
🗑  Удалить всё
```
 
Каждый компонент удаляется отдельно с подтверждением. При удалении страницы подписки конфигурация NGINX автоматически восстанавливается. Пункт **«Удалить всё»** убирает все обнаруженные компоненты одной операцией.

## 🔐 Безопасность и SSL
 
- **Cookie-защита панели** — вход по уникальной cookie-ссылке вместо прямого URL.
- **Мгновенная ротация cookie** — все старые ссылки инвалидируются в один клик.
- **Сброс суперадмина** — новые учётные данные без переустановки панели.
- **Переключение порта** — панель работает на `443` или `8443` по выбору.
- **SSL-сертификаты** — Let's Encrypt HTTP-01 или Cloudflare DNS-01 (wildcard).
- **DNS-проверка перед установкой** — скрипт убеждается, что домен указывает на текущий сервер.
- **Автоматическое обновление SSL** — при любой смене домена сертификат перевыпускается.

## 📋 Требования
 
**Операционная система:** Ubuntu 22.04 / 24.04 или Debian 11 / 12.
**Привилегии:** root или `sudo`.
**Сеть:** 2–3 поддомена с A-записями, направленными на IP сервера.
**SSL:** email для Let's Encrypt **или** Cloudflare API Token (нужен для wildcard DNS-01).
 
> Docker, Docker Compose и Certbot устанавливаются автоматически.
 
---
 
## 🔧 Решение проблем
 
**Перед установкой убедитесь, что:**
 
- Все домены указывают на IP сервера через A-записи.
- Порты `80` и `443` свободны.
- Firewall разрешает входящие соединения на портах `80`, `443`, `8443`.
- Email для Let's Encrypt введён корректно.
- При выборе DNS-01 — Cloudflare API Token имеет права на нужную зону.
 
**Если что-то пошло не так:**
 
1. `dfc → Remnawave → Просмотр логов` — посмотрите, что пишут контейнеры.
2. `dfc → Remnawave → Запустить сервисы` — попробуйте поднять сервисы заново.
3. Откройте [issue на GitHub](https://github.com/DanteFuaran/dfc-manager/issues) с текстом ошибки и шагами воспроизведения.
